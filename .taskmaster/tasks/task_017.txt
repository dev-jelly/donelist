# Subtasks:
## 1. 헬스/레디니스 엔드포인트 구현 및 종속 서비스 점검 [in-progress]
### Dependencies: None
### Description: 애플리케이션에 /healthz, /readyz 엔드포인트를 추가하고 DB, 캐시 등 핵심 종속 서비스 상태를 점검하여 가용성 신호를 표준화합니다.
### Details:
/healthz는 프로세스 생존 여부 중심, /readyz는 DB 연결 및 외부 종속성 ping을 포함하여 200 또는 503을 반환하도록 구현합니다. 빌드 정보와 git SHA를 응답에 포함하고 타임아웃을 명확히 설정합니다. 장애 모드별 원인 파악을 위한 세부 필드와 로그 연계를 추가합니다.

## 2. Prometheus 애플리케이션 계측 및 /metrics 노출 [in-progress]
### Dependencies: None
### Description: HTTP 지연, 응답 코드, 에러율, DB 커넥션 풀, 작업 큐 등 핵심 지표를 Prometheus 포맷으로 수집하고 /metrics에서 노출합니다.
### Details:
요청 지연 히스토그램(http_request_duration_seconds)과 요청 수 카운터(http_requests_total)를 라우트 템플릿과 상태코드 라벨로 수집합니다. 에러 카운터, DB 풀 게이지, 큐 대기 길이 등을 추가하고 기본 수집기(process, go) 활성화 및 라벨 카디널리티를 제한합니다. 미들웨어로 계측을 표준화합니다.

## 3. Prometheus 서버 및 스크레이프 설정 구성 [pending]
### Dependencies: 17.1, 17.2
### Description: 로컬과 K3s 환경에서 애플리케이션과 시스템 메트릭을 안정적으로 스크레이프하도록 Prometheus 구성을 준비합니다.
### Details:
prometheus.yml에 스크레이프 인터벌 기본 15s(중요 타깃 5s) 설정, 로컬 정적 타깃과 K8s ServiceMonitor/PodMonitor를 병행 지원합니다. 보존기간 15d, rule_files 디렉터리 분리, 필요 시 remote_write를 옵션으로 둡니다. TLS 및 인증이 필요한 타깃은 별도 잡으로 분리합니다.

## 4. Grafana 대시보드 설계·프로비저닝 (API/DB/시스템) [pending]
### Dependencies: 17.3

### Details:
API 대시보드에 QPS, p50/p95 지연, 에러율을 포함하고 DB 대시보드에 연결 수, 대기율, 슬로우 쿼리 지표를 배치합니다. 인프라 대시보드에 CPU, 메모리, 디스크, 네트워크 패널과 배포 주석을 추가합니다. 서비스와 환경을 변수로 템플릿화하고 패널 임계선과 링크를 구성합니다.

## 5. Alertmanager 연동 및 알람 룰 정의(Slack/메일) [pending]
### Dependencies: 17.3
### Description: 임계값 및 변화율 기반 알람을 정의하고 Slack과 이메일로 라우팅하여 신속한 대응을 가능하게 합니다.
### Details:
Alertmanager에 Slack 웹훅과 SMTP를 설정하고 severity 라벨 기반 라우팅과 그룹핑, 억제 규칙을 구성합니다. p95 지연 초과, 에러율 상승, 인스턴스 다운, DB 커넥션 포화, CPU 과다, 디스크 부족 알람 룰을 정의하고 각 알람에 runbook_url과 요약 라벨을 포함합니다. 소거(silence) 정책과 DND 창구를 문서화합니다.

## 6. OpenTelemetry 기반 분산 트레이싱 도입 및 메트릭·로그 연계 [pending]
### Dependencies: 17.2, 17.3
