# Task ID: 6
# Title: 주간 통계 분석 API 구현
# Status: pending
# Dependencies: 5
# Priority: high
# Description: 7일간의 생산성 통계 및 패턴 분석을 제공하는 API - 완전 구현 완료
# Details:
주간 통계 분석 API가 성공적으로 구현되었습니다. `/api/v1/statistics/weekly` 엔드포인트를 통해 포괄적인 주간 통계를 제공합니다.

**구현된 기능:**
- 주간 요약 통계 (총 체크인, 총 시간, 일별 평균, 완성률)
- 일별 세부 분석 (7일간 개별 통계)
- 요일별 패턴 분석 (가장 생산적인 요일 식별)
- 시간대별 분포 (아침/오후/저녁/밤 패턴)
- 카테고리별 분석 (카테고리별 체크인 수 및 시간)
- 주간 비교 분석 (전주 대비 변화율)
- 연속 기록 추적 (현재 연속 기록, 최장 연속 기록, 마일스톤)

**아키텍처 구성:**
- `internal/statistics/models.go`: 통계 데이터 모델 정의
- `internal/statistics/repository.go`: 데이터베이스 집계 쿼리 인터페이스
- `internal/statistics/service.go`: 비즈니스 로직 및 통계 계산
- `internal/api/handlers/statistics_handler.go`: HTTP API 핸들러
- `internal/api/routes/routes.go`: 라우트 등록 (/api/v1/statistics/weekly)

**지원 기능:**
- 타임존 지원 (IANA 타임존)
- 주 시작일 설정 가능 (일요일/월요일)
- 날짜 파라미터를 통한 특정 주 조회
- 캐시 만료 시간 설정
- 인터페이스 기반 리포지토리 패턴

# Test Strategy:
7개의 단위 테스트가 성공적으로 통과했습니다:
- 주간 경계 계산 테스트 (월요일/일요일 시작)
- 타임존 처리 테스트
- 시간대 분류 테스트 (아침/오후/저녁/밤)
- 요일 이름 계산 테스트
- ISO 주차 계산 테스트
- 연속 기록 마일스톤 테스트
- 전체 주간 통계 생성 테스트

**통합 테스트 준비:**
- API 엔드포인트 동작 테스트 필요
- 다양한 파라미터 조합 테스트 필요
- 성능 테스트 및 캐시 효율성 검증 필요
