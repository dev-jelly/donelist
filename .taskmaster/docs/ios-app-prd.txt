# DoneList iOS App - Product Requirements Document

## Project Overview
DoneList iOS 앱은 Go 백엔드 서버와 연동되는 시간 추적/체크인 애플리케이션입니다.

### Technical Stack
- UI Framework: SwiftUI Only
- Minimum iOS: iOS 17+
- Architecture: Clean Architecture
- Database: SwiftData
- Offline Support: Full (오프라인 큐 + Last Write Wins 동기화)

### Target
- 14주 개발 일정
- Full Feature 구현 (인증, 체크인, 타임라인, 캘린더, 통계, 검색, 구독, 동기화, 알림, 팀)

---

## Phase 1: Project Foundation (Week 1-2)

### Task: iOS 프로젝트 초기 설정
Create new Xcode project with SwiftUI App template. Configure for iOS 17+ deployment target. Set up project structure following Clean Architecture pattern.

### Task: SPM 모듈 구조 생성
Create Swift Package Manager local packages:
- DLCore: Common utilities, extensions, error types
- DLDomain: Entities, Use Cases, Repository Protocols
- DLData: Repository implementations, DataSources, DTOs, Mappers
- DLNetworking: API Client, Interceptors, Token Manager
- DLPresentation: ViewModels, Views, Coordinators
- DLSync: Offline queue, Sync engine
- DLIAP: StoreKit 2, Subscription management
- DLNotifications: Push notification handling

### Task: DLCore 모듈 구현
Implement core utilities:
- Date extensions (ISO8601 formatting, relative dates)
- String extensions (validation, trimming)
- UUID extensions
- AppError enum with localized descriptions
- Logger utility using OSLog
- Constants and configuration

### Task: DLNetworking API Client 구현
Implement networking layer:
- APIClient protocol with async/await
- APIClientImpl with URLSession
- Endpoint enum for all API routes
- HTTPMethod enum
- Request/Response interceptor chain
- AuthInterceptor for Bearer token
- LoggingInterceptor for debug
- RetryInterceptor with exponential backoff
- APIError enum with comprehensive error cases

### Task: Token Manager 구현
Implement secure token management:
- TokenManager protocol
- TokenManagerImpl using Keychain
- KeychainService for secure storage
- Access token caching with expiry check
- Refresh token rotation handling
- Automatic token refresh on 401

### Task: SwiftData 스키마 정의
Define SwiftData models:
- UserEntity
- CheckinEntity with tags relationship
- CategoryEntity
- TagEntity
- SyncOperationEntity for offline queue
- SyncStatusEntity for device sync state
- CacheMetadataEntity for ETag support
