Store authenticated user info in Client struct. Handle token refresh mechanism for long-lived connections.

## 5. Implement Offline Message Queue with Redis Streams [pending]
### Dependencies: 3.3
### Description: Build message queuing system using Redis Streams to store messages for offline users and deliver upon reconnection
### Details:
Use Redis XADD to append messages to user-specific streams (stream key: messages:user:{uuid}), implement XREAD to retrieve pending messages on reconnect, add message TTL of 7 days, implement acknowledgment system for delivered messages using XACK, handle stream trimming to prevent unbounded growth. Include retry logic for failed deliveries.

Add jitter to prevent thundering herd.
