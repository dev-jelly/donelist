### Details:

## 2. Implement webhook service with event dispatcher using goroutines [pending]
### Dependencies: 7.1
### Description: Create the core webhook service that handles event dispatching asynchronously using goroutines and channels
### Details:
Create WebhookService struct with methods: DispatchEvent(eventType, payload), processWebhook(webhook, event). Implement worker pool pattern with configurable number of goroutines (default 10). Use buffered channels for event queue (capacity 1000). Add context support for graceful shutdown. Implement event filtering to only dispatch to webhooks subscribed to specific events (checkin.created, checkin.updated, user.upgraded).

## 3. Add HMAC signature generation and verification [pending]
### Dependencies: 7.2
### Description: Implement secure webhook payload signing using HMAC-SHA256 for request authentication
### Details:
Create signature package with GenerateSignature(secret, payload) and VerifySignature(secret, payload, signature) functions. Use HMAC-SHA256 algorithm. Add X-Webhook-Signature header to all webhook requests. Include timestamp in signature to prevent replay attacks. Store webhook secrets encrypted in database using AES-256. Add signature verification middleware for incoming webhook responses.

## 4. Implement retry logic with exponential backoff [pending]
### Dependencies: 7.2
### Description: Add intelligent retry mechanism for failed webhook deliveries with exponential backoff strategy
### Details:
Implement retry strategy with exponential backoff: initial delay 1s, max delay 1 hour, max retries 10. Use formula: delay = min(initialDelay * 2^attemptNumber, maxDelay). Add jitter to prevent thundering herd. Store retry state in database (retry_count, last_attempt_at, next_retry_at). Implement circuit breaker pattern to temporarily disable webhooks after consecutive failures. Add HTTP timeout of 10 seconds for webhook requests.

Add monitoring dashboard using Asynq's built-in UI. Configure max concurrent workers based on system capacity.
