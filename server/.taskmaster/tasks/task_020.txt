# Details:
Implement comprehensive dual-mode UI/UX system with the following components:

1. **Mode Detection & Selection System** (internal/mode/service.go):
   - Create UserMode enum (personal, team) with default preference storage in users table
   - Implement mode detection middleware that sets context based on user preference or URL prefix (/personal, /team)
   - Build mode switching API endpoint POST /api/v1/users/mode with validation
   - Add mode field to JWT claims for stateless mode detection

2. **Routing Architecture** (internal/api/routes/routes.go):
   - Implement route prefixing: /api/v1/personal/* and /api/v1/team/* with shared middleware
   - Create mode-aware middleware that validates access (team features require collaboration permissions)
   - Duplicate critical endpoints with mode-specific behavior (checkins, analytics, timelines)
   - Implement cross-mode data sharing controls (personal checkins visible in team mode based on privacy settings)

3. **Personal Mode Features** (internal/personal/*):
   - Minimal UI components focused on individual productivity tracking
   - Personal dashboard with streak tracking, personal goals, private categories
   - Individual timeline views (daily/weekly personal summaries)
   - Personal analytics without team comparison features
   - Quick checkin flows optimized for single-user experience

4. **Team Mode Features** (internal/team/*):
   - Team dashboard with real-time collaboration using existing WebSocket infrastructure
   - Shared timelines showing team member activities with privacy controls
   - Team analytics with member comparison, team goals, shared categories
   - Real-time presence indicators and typing notifications via WebSocket
   - Team member management (invite, remove, role assignment)

5. **Database Schema Extensions**:
   - Add user_mode_preference enum to users table with default 'personal'
   - Create teams table with team_id, name, settings, created_at
   - Create team_members table with team_id, user_id, role, joined_at
   - Add team_id foreign key to checkins table for team-shared checkins
   - Create team_categories table for shared category management

6. **Mode-Specific Components**:
   - Personal: MinimalCheckinForm, PersonalDashboard, StreakDisplay, PersonalTimeline
   - Team: TeamDashboard, CollaborativeCheckinForm, TeamMemberList, SharedTimeline, RealTimeActivityFeed
   - Shared: ModeSelector, UserPreferences, CommonHeader with mode indicator

7. **User Experience Enhancements**:
   - Smooth mode transition animations with data context preservation
   - Mode-specific navigation patterns (sidebar for team, bottom nav for personal)
   - Different color schemes and layouts per mode
   - Mode-aware notifications and real-time updates
   - Export functionality with mode-specific data filtering
